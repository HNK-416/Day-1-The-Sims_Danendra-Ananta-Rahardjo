Repository untuk merangkum informasi yang di berikan di workshop

Tujuan dari repository adalah untuk menyimpan, mengelola, mengorganisasi, dan melacak perubahan pada file atau kode sumber proyek. Selain itu, repository juga berfungsi untuk memudahkan proses backup data.

Poin 1: Promp Engineering
Prompt adalah instruksi atau masukan yang diberikan kepada AI untuk mendapatkan hasil tertentu. Struktur prompt yang baik terdiri dari role (menentukan peran AI), task (menentukan tugas spesifik), context (memberikan latar belakang atau batasan), dan format (menentukan bentuk keluaran yang diinginkan). Penggunaan prompt yang terstruktur ini bisa meningkatkan performa AI, mengurangi kesalahan, meningkatkan prediktabilitas, serta memberikan pengalaman yang lebih baik

Poin 2: Git Workflow
Proses pencatatan perubahan kode lokal dikelola melalui tiga area utama, yaitu Working directory, staging area (tempat penampungan sementara), dan Git directory (repositori penyimpanan metadata)

Poin 3: Perbedaan Git dan Github
Git: Sistem version control terdistribusi (DVCS) yang digunakan untuk melacak dan mengelola perubahan kode secara lokal
Github: Platform berbasis web yang digunakan untuk menyimpan repository Git secara online dan mendukung kolaborasi

Poin 4: Command Esensial Git & GitHub
git init: Membuat repository baru
git add.: Memindahkan file ke staging area
git commit -m 'message': Menyimpan file ke Repository
git remote add <name> <url: Add untracked file or unstaged changes
git push origin main: Push the current branch to its remote "tracking branch"
git pull origin main: Fetch changes and then merge them into 
your current branch

Poin 5: Setup Git
1. Instal Git: Search google “install git”
2. Pilih versi yang sesuai dengan device
3. Buka terminal/cmd: Type git --version dan git version 2.xx.xx setelah itu
4. Setup Git identity: Type git config --global user.name "Your Name" dan git config --global user.email "your-email@example.com" setelah itu
5. Check config: Type git config --global --list

Poin 6: Setup VS Code
1. install VSCode dan buka VSCode
2. Tekan Command+Shift+P / Ctrl+Shift+P
3. Search Shell Command: Install 'code' command in PATH
4. Buka terminal dan type code --version
